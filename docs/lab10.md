## Ажиллуулах

```bash
npm test                    # бүх тест
npm run test:coverage       # coverage тайлантай (босго: lines, branches ≥ 80%)
npx jest tests/lab10.eligibility.test.js --verbose
```

## CI

`build-and-test` job `npm run test:coverage` командыг ажиллуулна. Coverage-ийн хүснэгт run-ийн **Summary** хэсэгт гарч, бүрэн тайлан `coverage-report` artifact болж хадгалагдана. Coverage 80%-иас доош унавал CI улаан болно.

## Санаатай унагаах туршилт (8-р алхам)

`src/graduation.js` дахь `grad >= limit` нөхцлийг `grad > limit` болгож өөрчилнө. Ингэвэл яг 2 жилийн өмнө төгссөн хүн шалгуурт тэнцэхгүй болно. Энэ өөрчлөлтийг PR дээр push хийхэд «яг 2 жилийн өмнө төгссөн бол тэнцэнэ» тест унаж, PR улаан болно.

Өмнөх 20 тест энэ хилийн алдааг илрүүлж чадаагүй. Энэ нь хилийн тохиолдлын тест хэрэгтэйг харуулж байна.
