## Prompt-ын харьцуулалт

| Шалгуур | Ерөнхий prompt (`login function бичээд өг`) | Тодорхой prompt |
| --- | --- | --- |
| Технологи | **Python/FastAPI** (төсөл Node.js) | Node.js 20, CommonJS ✓ |
| Интерфейс | Өөрөө зохиосон endpoint, JWT | Яг өгсөн гарын үсэг ✓ |
| Шаардлагагүй зүйл | JWT, `pip install`, `main.py`, env хувьсагч | Байхгүй |
| Тест | **0** | 42 (AAA, `jest.fn()`, хилийн утга) |
| Аюулгүй байдал | Enumeration, timing-ийн хамгаалалт ✓; урт нууц үгийг чимээгүй `False` буцаана | Шаардлагын 7 зүйл бүгд ✓ |
| Төсөлд шууд ашиглах боломж | Үгүй | Review хийсний дараа тийм |
| Өөрийн хязгаарлалтыг дурдсан | Хэсэгчлэн | 6 зүйл (ажиллуулж шалгаагүй гэдгээ хэлсэн) |

**Дүгнэлт:** ерөнхий prompt-д AI таамаглал хийж дутуу мэдээллийг нөхсөн бөгөөд технологи нь хүртэл буруу гарсан. Тодорхой prompt-д технологи, интерфейс, хилийн утга, аюулгүй байдлын нөхцлийг заасан тул хариу шууд ашиглахад ойр болсон. Гэхдээ prompt-д байсан алдаа (`isActive === false`) кодод үгчлэн орсон. Иймд prompt сайн байх нь review хийх шаардлагыг арилгадаггүй.

## Review-ийн үр дүн

4 асуудал олдсон: High 1, Medium 1, Low 2. Хамгийн ноцтой нь идэвхгүй дансыг нэвтрүүлдэг **fail-open** алдаа. Дэлгэрэнгүйг [03-review.md](lab12/03-review.md)-аас үзнэ үү.
